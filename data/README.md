# Data

The files are not versioned: they were provided by OpenClassrooms for the project, and the chart file weighs 1.4 GB.

To run the notebooks, put the three files here:

| File | Used by |
|---|---|
| `spotify-tracks-dataset-detailed.csv` | Part 1 |
| `chart_tracks_genre_2017_2020.csv` | Part 2 |
| `release_dates_genre_2017_2020.csv` | Part 2 (release cadence) |

The notebooks and `presentation/build_figures.py` read them with the relative path `../data/`.
